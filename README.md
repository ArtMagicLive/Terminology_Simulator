> Приложение «Терминологический тренажер» представляет собой консольную программу, написанную на C# (.NET 8).
> Оно предназначено для создания, редактирования и структурированного хранения тематических наборов терминов,
> а также для интерактивной проверки знаний пользователя с автоматическим ведением статистики и истории сессий.

**Реализовано**
-----
- **Работа с файлами и хранилищем.** Все данные приложения (наборы терминов, история тренировок и статистика ошибок) автоматически сериализуются и сохраняются в локальный JSON-файл. При повторном запуске состояние системы полностью восстанавливается.
- **Поиск и контекстные действия.** Реализован сквозной поиск терминов по названию во всех существующих наборах. Прямо из меню поиска можно мгновенно перейти к редактированию, удалению записи или добавлению нового варианта ответа.
- **Умный режим тренировки.** Программа поддерживает запуск тестов по конкретным темам или в смешанном режиме. Система генерирует случайную выборку из 20 вопросов, проверяет ответы на полное совпадение с учетом регистра и выводит итоговый процент успешности.
- **Аналитика и статистика.** Ведется история всех прошлых тренировок. Реализован алгоритм подсчета самых сложных для пользователя вопросов на основе количества совершенных ошибок.
- **Экспорт данных.** Добавлена функция выгрузки отдельной карточки термина или всего выбранного набора в читаемый текстовый файл (`.txt`).

**Структура проекта**
-------
| Файлы и папки | Их назначение |
| ------------- | ------------- |
| `Program.cs` | Точка входа в приложение, инициализация слоев и запуск главного меню |
| `Models/` | Папка с моделями данных (`Term`, `TermSet`, `AppState`, `SessionResult`, `ErrorStatistics`) |
| `Storage/` | Компоненты сохранения данных (`IStorageService`, `JsonStorageService`) |
| `Services/` | Бизнес-логика приложения (`TermManager` — управление данными, `TrainingService` — механика тестов) |
| `Presentation/` | Консольный интерфейс пользователя и интерактивная навигация (`ConsoleMenu`) |
